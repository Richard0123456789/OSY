# Porovnanie nástrojov virtualizácie

## Tabuľka porovnania

| Nástroj               | Cena                        | Platforma                | Výhody                                                                 | Nevýhody                                                              |
|-----------------------|-----------------------------|---------------------------|-------------------------------------------------------------------------|------------------------------------------------------------------------|
| **VirtualBox**        | Zadarmo (open-source)       | Windows, Linux, macOS     | - Jednoduché používanie<br>- Podpora mnohých OS<br>- Bezplatný         | - Slabší výkon pri náročných úlohách<br>- Menej profesionálnych funkcií |
| **VMware Workstation Pro** | Platený               | Windows, Linux            | - Veľmi dobrý výkon<br>- Profesionálne funkcie<br>- Stabilita          | - Vysoká cena<br>- Nie je pre macOS<br>- Zložitejší pre začiatočníkov |
| **Hyper-V**           | Zadarmo s Windows Pro/Ent   | Windows                   | - Vysoký výkon<br>- Natívna integrácia vo Windows<br>- Spoľahlivý       | - Funguje iba na Windows<br>- Slabšia podpora pre niektoré OS         |
